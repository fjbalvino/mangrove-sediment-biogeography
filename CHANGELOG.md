# Changelog

All notable changes to the public workflow will be documented here.

## [Unreleased]

- Added accession manifests and a configurable runner for taxonomic analyses.
- Updated Hill diversity comparisons to use coordinate-defined sites, with
  supplementary richness (q = 0), dominance-weighted diversity (q = 2) and
  taxonomic dominance summaries.
- Updated the environmental GAM and its figures, statistical tables,
  concurvity checks and residual diagnostics.
- Updated taxonomic ordination, geographic distance decay, regional PERMANOVA
  and dispersion tests, and environmental–spatial variation partitioning.
- Corrected selection of single samples per site and rank checks for
  conditional variation-partitioning models; added regression tests.
- Clarified locality balancing, core read denominators, and the external
  reference phylogeny used for genus-level iCAMP inference.
- Replaced analysis-specific personal paths and unexplained sample-selection
  labels with documented input files, accession manifests and configuration.

- Organized the canonical analytical workflow into objective-based blocks.
- Added GitHub validation, citation metadata and GitHub–Zenodo–SRA guidance.
- Reserved Block 07 for the pending MEGAHIT-to-KO construction workflow.
