# External inputs

Datasets and reference assets are not stored in this code repository.

Obtain the files in [DATA_AVAILABILITY.md](../DATA_AVAILABILITY.md), verify their checksums and place them here or set `MAGENTA_DATA_DIR` / stage-specific paths in `config/project.env`.

The companion data/figure deposit on Zenodo is pending. A source checkout does not contain count matrices, metadata tables, trees, maps, databases or published figures.
