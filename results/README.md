# Current analysis results

`taxonomic_summary.json` records full-precision summaries for the 341-profile
reference and its analysis-specific subsets. iCAMP is explicitly marked as the
retained result from its separate 400-profile analysis. It was not repeated.

The companion archive supplies the count object, metadata, full statistical
outputs, fitted objects, figures and manuscripts. Figure 2a–d uses the current taxonomic reference. Figure 3 combines the
core analysis with the separately retained iCAMP estimates in
`icamp/icamp_process_contributions.tsv`.

The primary manuscript interpretation must distinguish site-level inference,
profile-level descriptions, locality-pooled core calculations and the separate
iCAMP cohort. See `docs/TAXONOMIC_ANALYSES.md` for definitions and limitations.

## Functional atlas

`functional/` contains the compact statistical results for 191 matched profiles,
including site-level PERMANOVA and PERMDISP, count-adjusted and Hellinger
sensitivity analyses, Mantel tests, geographic slope contrasts, and sampling
sensitivity summaries. Full classifications, loadings, pairwise distances and
sample metadata are supplied in the companion archive and regenerated by the
functional workflow. The functional count denominator is KO annotation counts.

Figure 4 and Supplementary Figure S4 are generated locally under
`figures/functional/` by the functional workflow. The PNG images are omitted from
this repository update.
The results text and caption are in `docs/FUNCTIONAL_RESULTS.md`.

## Functional network

`functional_network/` contains the corrected Figure 5 statistics for 191 profiles.
The full network has 1,062 associations among 327 connected KOs; six major
modules contain 236 KOs and 999 associations. Enrichment uses 4,999 blocked
permutations and the complete 42-comparison family. M01 and M06 retain support
under both annotation treatments; M03 is annotation-sensitive.

The tables include 500 edge perturbations, 30 threshold combinations, alternative
community algorithms, and omission of each of 43 BioProjects. One unresolved
project-label omission is reported separately. Omitting six PRJNA437562 profiles
changes the network substantially; all 191 profiles remain in the primary analysis.

The accepted text and caption are in `docs/FUNCTIONAL_NETWORK_RESULTS.md`;
Supplementary Tables S14–S27 are in `docs/FUNCTIONAL_NETWORK_SUPPLEMENTARY_RESULTS.md`.
Execution and input requirements are in `docs/FUNCTIONAL_NETWORK_ANALYSES.md`.
Source-data verification records accompany the tables. Images, binary reports,
raw matrices and fitted objects are excluded from the repository.
