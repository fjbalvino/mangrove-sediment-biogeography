# Local analysis outputs

This directory contains generated outputs only on your machine. Numerical tables, fitted objects, figures and logs are excluded from the code repository.

The numerical summaries previously tracked in Git were preserved for the separate data companion. When supplied, place those reference summaries under `data/reference_results/`; do not mix them with fresh runs. The retained iCAMP process table is configured through `ICAMP_SUMMARY_TSV`.

See [data availability](../DATA_AVAILABILITY.md) and the [manuscript guide](../docs/MANUSCRIPT_GUIDE.md) for status, cohorts and figure mapping.
