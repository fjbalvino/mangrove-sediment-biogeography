# Verified Figure 5 summaries

These files derive from the corrected 191-profile functional cohort and the complete 499-selection runs. The `180_verified_*` summaries are authoritative for report numbers and Figure 5 interval definitions. In particular, deletion intervals are full ranges across exclusion medians; other sensitivity intervals are 5th–95th percentiles across paired selections. Full selected accession lists, per-selection diagnostics, the 9,886-KO contribution table and RDS object are distributed in the companion package.

Counts are KO annotation assignments. R² denotes subcomposition-specific variation. Study and realm are confounded. P-value frequencies are nominal sampling diagnostics, not independent replication. The contribution audit does not test pathway enrichment.

The restored process/map panels are summarized by `181_process_catalog_validation.tsv`, `181_process_regional_summary.tsv`, `181_process_heatmap.tsv` and `182_shell_locality_turnover_summary.tsv`. The `181_182` audit and independent base-R verification record the current 191-profile cohort, 33 selected Shell KOs, 26 named localities and 23 mapped units. Full draw-level scores, selections, bootstrap replicates and NPZ objects remain in the companion archive. Per-process R² is not a contribution to all-KO variation.
